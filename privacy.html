Privacy policy: Gmail Connector (personal)

Last updated: 6 November 2026

Who uses it

Gmail Connector is a private tool used only by its owner, for the owner's own Gmail accounts. It is not offered to anyone else.

What it accesses

It asks Google for read-only Gmail access (gmail.readonly). It can search and read emails and attachments. It cannot send, change or delete anything.

Where data goes

Emails and attachments are downloaded only to the owner's own computer.

They are never sent to any server, never shared with third parties, never sold, and never used for advertising.

Google sign-in tokens are stored in the owner's computer's secure keychain.

Google API data

The use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
